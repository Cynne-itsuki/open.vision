# お金と暮らしの事前アンケート

GitHub Pagesで公開し、回答をGoogleスプレッドシートへ保存する面談前アンケートです。

## 目的

- 氏名、年齢、働き方、家族構成の確認
- 年収帯、金融資産、積立余力、借入、保険加入状況の確認
- 相談テーマに応じたFP・保険担当者の振り分け
- 商品提案や契約判断ではなく、面談前の状況整理

## UI仕様

- 選択肢をタップすると自動で次の質問へ進む
- 氏名入力と最終同意のみ「次へ／回答を送信」を使用
- スマートフォン対応
- 回答後は商品や保険の診断結果を表示しない

## 公開前の必須設定

`app.js` 冒頭の `CONFIG` を編集します。

```js
const CONFIG = {
  endpoint: 'Google Apps ScriptのウェブアプリURL',
  operatorName: '実際の個人情報取扱事業者名',
  recipientDescription: '実際の提供先または提供先の明示方法',
  privacyContact: '問い合わせ用メールアドレス等'
};
```

事業者名、第三者提供先、保存期間、削除手続、問い合わせ窓口は、公開前に実態に合わせて確定してください。

## Googleスプレッドシート連携

1. 回答保存用のGoogleスプレッドシートを作成する。
2. `拡張機能` → `Apps Script` を開く。
3. `gas/Code.gs` の内容を貼り付ける。
4. `デプロイ` → `新しいデプロイ` → `ウェブアプリ` を選ぶ。
5. 実行するユーザーを自分、アクセスできるユーザーをフォーム利用者がアクセス可能な設定にする。
6. 発行されたURLを `app.js` の `CONFIG.endpoint` に設定する。
7. テスト回答を行い、`insurance_survey` シートへ行が追加されることを確認する。

## URLパラメータ

流入元をスプレッドシートに保存できます。

```text
/insurance-survey/?source=crowdworks&campaign=interview_01&ref=USER123
```

- `source` または `utm_source`
- `campaign` または `utm_campaign`
- `ref`

## 振り分けタグ

回答内容から次のタグを作成して保存します。

- `lump_sum`
- `inheritance_realestate`
- `family_protection`
- `asset_building`
- `household_review`
- `insurance_review`
- `general`

`readiness` は相談意向と検討時期から `high / medium / low` を算出します。資産額だけで優先順位を決める設計にはしていません。

## コンプライアンス上の注意

- この画面では、具体的な保険商品、利回り、保険料、推奨プランを表示しない。
- 健康状態、病歴、障害、性生活などの機微情報は取得しない。
- 実際の保険提案・推奨・募集は、適切な資格・権限を持つ担当者が、意向把握・確認を行ったうえで実施する。
- 個人情報の利用目的と提供先を回答前に明示し、同意記録を保存する。
- Googleスプレッドシートの共有権限を必要最小限に設定する。
- 公開前に、保険代理店のコンプライアンス担当または専門家の確認を受ける。
