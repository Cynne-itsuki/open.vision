# 面談前アンケート（テスト版）

GitHub Pagesで公開し、回答をGoogleスプレッドシートへ保存する簡易アンケートです。

## 質問項目

1. 本名（必須入力）
2. 年齢
3. 働き方
4. 本人年収
5. 最も相談したいテーマ
6. 面談で希望すること

## 動作

- 本名入力後は「次へ」を押す
- 選択式の質問は、選択肢を押すと自動で次へ進む
- 最後の「面談で希望すること」を選択した時点で、自動送信する
- 個人情報同意画面は表示しない
- 回答後は完了画面を表示する

## Googleスプレッドシート連携

1. 回答保存用のGoogleスプレッドシートを作成する。
2. `拡張機能` → `Apps Script` を開く。
3. `gas/Code.gs` の内容を貼り付ける。
4. `デプロイ` → `新しいデプロイ` → `ウェブアプリ` を選ぶ。
5. 実行するユーザーを自分、アクセスできるユーザーをフォーム利用者がアクセス可能な設定にする。
6. 発行されたURLを `app.js` 冒頭の `CONFIG.endpoint` に設定する。
7. テスト回答を行い、`insurance_survey_test` シートへ行が追加されることを確認する。

```js
const CONFIG = {
  endpoint: 'Google Apps ScriptのウェブアプリURL'
};
```

## 保存項目

- サーバー受信日時
- 回答端末日時
- 流入元
- キャンペーン
- 参照ID
- 氏名
- 年齢
- 働き方
- 本人年収
- 最も相談したいテーマ
- 面談で希望すること
- 回答ページURL

## URLパラメータ

```text
/insurance-survey/?source=crowdworks&campaign=interview_01&ref=USER123
```

- `source` または `utm_source`
- `campaign` または `utm_campaign`
- `ref`
